Foot IK
Project Details
In most modern AAA games, realistic foot placements are quite common. However, I could hardly find any resources online about how to implement it in Unity. I took it upon myself to research Unity's Inverse Kinematics in-depth to script a user friendly plugin that allows developers to inject realistic foot placements in any animation.

This plugin also solves jittery movement on stairs. Unity's default character controller does not smoothly interpolate the pelvis when walking up steps. My plugin solves this problem by using complex colliders for precise ray collisions while maintaining smooth pelvis movement as if the character is walking on a slope.
