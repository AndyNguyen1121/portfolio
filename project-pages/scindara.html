Project Background
The hack-and-slash genre has always been one of my favorites. Games like Metal Gear Rising: Revengence, NieR: Automata, Devil May Cry, and God of War are my main motivators for developing this project. I absolutely adore this genre, so I wanted to take a crack at creating a game in it. Although this project had its flaws, the passion and care I poured into it shaped me into the developer I am today.
Combat System
This project contains the very first iteration of the combat system that would be evolved to be used in future projects like SPAR-K-RUMBLE and
Souls-like Showcase.

This combat system uses Unity's scriptable objects to store attack data and inputs. This data is sent into a custom state machine manager that process the data and determines if the criteria has been met for the player to activate an ability.
Enemy Behavior
To control my enemy behavior, I programmed my own behavior tree from scratch (I didn't know Unity already had one). To prevent the enemies from overwhelming the player, I used a token system.

The player has a maximum of three tokens. If an enemy wants to attack a player, they have to request a token from the player. If the player does not have anymore tokens, then the enemy can't attack and must strafe around the player until their token request goes through. This means only a maximum of three enemies may attack the player at one time.

// Code example of custom-made behavior tree public void CreateEnemyBehaviorTree() { enemyBehaviorTree = new BehaviorTree("EnemyBehaviorTree"); Selector activeStatus = new Selector("IsEnemyAlive"); enemyBehaviorTree.AddChild(activeStatus); // Alive Sequence isAliveSequence = new Sequence("AliveSequence"); activeStatus.AddChild(isAliveSequence); isAliveSequence.AddChild(new Leaf("CheckIsAlive", new Condition(() => enemyManager.isAlive))); // Handles Attack and Movement isAliveSequence.AddChild(ActivityTree()); // Dead Sequence isDeadSequence = new Sequence("IsDead"); isDeadSequence.AddChild(new Leaf("CheckIfDead", new Condition(() => !enemyManager.isAlive))); activeStatus.AddChild(isDeadSequence); isDeadSequence.AddChild(new Leaf("PrintIsDead", new ActionStrategy(StartDeathSequence))); } private Node ActivityTree() { Sequence attackAndMovementSeq = new Sequence("AttackAndMovement"); attackAndMovementSeq.AddChild(new Leaf("IsStunned", new Condition(() => !isStunned))); Selector attackOrMove = new Selector("AttackOrMove"); // Attack Sequence Sequence attackSeq = new Sequence("AttackSequence"); attackSeq.AddChild(new Leaf("CanAttack", new Condition(() => enemyManager.canAttack))); attackSeq.AddChild(new Leaf("IsInRange", new Condition(() => targetInRange))); attackSeq.AddChild(new Leaf("HandleAttacks", new ActionStrategy(HandleAttacks))); attackOrMove.AddChild(attackSeq); // Movement Sequence attackOrMove.AddChild(new Leaf("HandleMovement", new ActionStrategy(HandleMovements))); attackAndMovementSeq.AddChild(attackOrMove); return attackAndMovementSeq; }
